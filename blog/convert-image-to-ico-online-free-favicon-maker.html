What You Should Know Before Converting to ICO

The ICO format is unlike any other image format you've worked with. Understanding its unique structure before you start will save you from a lot of confusion — especially the kind where your favicon looks perfect in one browser but is missing or blurry in another.

The most important thing to know: an ICO file is a container, not just an image. It can hold multiple images of different sizes inside a single file — and that's intentional. When a browser needs your favicon for a tab (16×16 pixels), it picks the 16×16 version from inside your ICO. When Windows needs an icon for a shortcut (48×48 pixels), it picks the 48×48 version. A single well-constructed ICO file serves all these contexts automatically.

Second: your source image quality determines the ICO quality. ICO files support transparency (PNG-based ICO layers), but if you convert a JPG to ICO, you get a JPEG layer with no transparency support. For a favicon, you almost always want a PNG source with transparent background so your logo sits cleanly in browser tabs regardless of whether the user is in light mode or dark mode.

Third: modern websites use more than just favicon.ico. Apple touch icons (180×180 PNG), Android/PWA icons (192×192, 512×512 PNG), and Windows tile icons are separate files — not ICO. The ICO file is specifically for the browser tab favicon and Windows desktop shortcuts. A complete favicon implementation usually involves an ICO file plus several additional PNG files.

ICO File Sizes — What Each One Is Used For

Before you convert, know which sizes to include. A proper multi-size ICO covers all the contexts where your icon will appear:

16×16 Browser tab favicon on all major browsers Required
32×32 Windows taskbar, browser address bar, bookmark icons Required
48×48 Windows desktop shortcuts and file explorer Recommended
64×64 High-DPI tab bars and Retina displays Recommended
128×128 macOS Dock, large Windows icon views Optional
256×256 Windows applications, highest quality contexts Optional

For a website favicon, 16×16 + 32×32 is the minimum. Adding 48×48 and 64×64 makes your favicon sharp across retina displays and Windows shortcuts. Including 128×128 and 256×256 is only necessary if you're distributing the ICO as a software application icon, not just a web favicon — those sizes add significant file size without visible benefit in a browser tab.

⚠️ Important: At 16×16 pixels, your favicon is 256 individual pixels total. A complex logo with text, thin lines, or multiple colors will be completely unrecognizable at this size. The most effective favicons at small sizes are: a single bold letter, a simplified geometric symbol, a clean monogram, or a solid icon. If your logo doesn't work at 16×16, design a simplified version specifically for favicon use.

Step-by-Step: How to Convert an Image to ICO Online

Here is the complete workflow — from preparing your source image to placing the favicon.ico correctly on your website.

1

Prepare Your Source Image

The single most important step is starting with the right source file. The ideal input for favicon creation is a PNG file with a transparent background, square dimensions, and at least 512×512 pixels. Here's why each of those matters: transparent background means the icon looks clean on any browser background color; square dimensions mean the icon won't get distorted when resized to 16×16; 512×512 pixels minimum means there's enough resolution for the tool to create sharp downscaled versions.

If you're starting from a JPG (no transparency), convert it to PNG first, or use a background-removal tool to make the background transparent before the ICO conversion. If you're starting from an SVG, most ICO converters accept SVG directly and handle the rasterization step for you. If your source image is rectangular rather than square, crop or add padding to make it square before converting.

📐 512×512 PNG with transparent background = ideal input
2

Choose the Right Conversion Tool

For most people, favicon.io (favicon.io/favicon-converter) is the best starting point — it's purpose-built for web favicons, generates the ICO plus all the Apple and Android PNG variants you need, and is completely free. For a simple ICO conversion without the extra PNG files, icoconvert.com or convertio.co work well. For batch conversions or more size control, cloudconvert.com gives you fine-grained ICO options.

Avoid generic image converter sites that happen to list ICO as an output format — many of these produce single-size ICO files (only 32×32) that look blurry in high-DPI contexts and miss the 16×16 size that browsers prefer for tabs.

✅ favicon.io is the best all-in-one choice for web favicons
3

Upload and Select Output Sizes

On favicon.io, click "Select your image" and upload your prepared square PNG or SVG. The tool will automatically include 16×16, 32×32, 48×48, and 64×64 in the generated ICO. On icoconvert.com, after uploading you can manually check which sizes to include — tick at least 16×16 and 32×32, and also 48×48 and 64×64 for better retina coverage. On convertio.co, after selecting ICO as the output format, look for "Settings" where you can specify image dimensions.

On cloudconvert.com, after uploading go to the "Options" panel. Under "Image Size," enter the sizes you want — you can add multiple target sizes which get embedded in the ICO container. For a standard web favicon, enter 16, 32, 48 as separate size values.

📋 Always include 16, 32, and 48 at minimum
4

Verify Transparency is Preserved

Before downloading, check the preview if the tool offers one. The icon should show your logo/symbol on a checkered background (the standard indicator for transparency) — not on a white or colored fill. If the background shows as white, either your source image wasn't transparent or the tool doesn't support PNG-based ICO layers. Switch to a tool that explicitly supports "PNG ICO" or "24-bit ICO with transparency."

ICO files can use two internal formats: the older BMP/DIB format (limited color, no real transparency) and the newer PNG format (full 24-bit color with alpha channel transparency). Good modern tools default to PNG-format ICO layers. Always confirm your tool is using PNG layers, especially if transparency is important to your favicon design.

🔲 Checkered background in preview = transparency preserved ✅
5

Download the ICO File and Rename It

Download the generated file. Most tools name it something like "favicon.ico" already, which is exactly what you want. If the tool names it differently (like "download.ico" or "output.ico"), rename it to favicon.ico — this is the conventional filename that browsers look for automatically at your domain root, even without a specific HTML link tag (though you should still add the link tag as a best practice).

If you used favicon.io, you'll download a ZIP file containing favicon.ico plus several PNG files (apple-touch-icon.png, android-chrome-192x192.png, android-chrome-512x512.png) and a site.webmanifest file. All of these are useful — keep them all and upload the full set to your website.

📁 Rename to favicon.ico if tool gives it a different name
6

Upload to Your Website and Add the HTML Link Tag

Upload favicon.ico to the root directory of your website — the same folder that contains your main index.html. This is important: placing it in a subfolder (like /images/favicon.ico) technically works with the link tag, but many automated browser lookups specifically look for /favicon.ico at the domain root. Keeping it at root ensures maximum compatibility.

Then add this line inside your HTML <head> section:

<!-- Favicon link tag — add inside <head> -->
<link rel="icon" type="image/x-icon" href="/favicon.ico">

<!-- If you also have PNG icons (from favicon.io) -->
<link rel="apple-touch-icon" href="/apple-touch-icon.png">
<link rel="manifest" href="/site.webmanifest">
📂 Place favicon.ico in root folder — same level as index.html
7

Test and Verify Across Browsers

After uploading, open your website in Chrome, Firefox, and Edge and check the browser tab — your favicon should appear. If it doesn't appear immediately, do a hard refresh (Ctrl+Shift+R on Windows, Cmd+Shift+R on Mac) to clear the browser's favicon cache. Browsers are notoriously aggressive about caching favicons.

To test on iOS Safari, open your site on an iPhone and use "Add to Home Screen" — the icon shown there will be your apple-touch-icon. To test how the favicon appears at different sizes, use the excellent free tool at realfavicongenerator.net/favicon_checker which checks your favicon across multiple browsers and devices simultaneously and tells you exactly what's missing or wrong.

🔄 Hard refresh (Ctrl+Shift+R) if favicon doesn't update immediately

A missing favicon is one of the clearest signals that a website is unfinished. For any professional, business, portfolio, or commercial website, having a correct favicon is baseline — not optional. It's one of those details that users don't consciously notice when present, but immediately notice when absent.

✅ Bottom line: A properly implemented favicon takes less than 5 minutes to set up and delivers lasting benefit — brand recognition in tabs, bookmarks, search results, and home screen icons. It's one of the highest ROI improvements you can make to any website.

Common Mistakes When Converting to ICO

These are the errors that come up again and again — from both first-time website builders and experienced developers who haven't dealt with favicons in a while.

❌ Mistake 1: Using a Rectangular Image as the Source

When you convert a non-square image to ICO, the converter has to decide what to do with the extra space. Most tools either crop to a square (cutting off part of your image) or stretch the image to fill a square (distorting your logo). At 16×16 pixels, either outcome looks terrible and often makes your brand mark unrecognizable.

✅ Fix: Before converting, ensure your source image is square. If your logo is wider than it is tall (common for horizontal brand marks), add equal padding on the top and bottom to make it square — use any image editor or an online padding tool. The icon area can be smaller within the square frame.

❌ Mistake 2: Converting a Detailed or Complex Logo Directly

A logo with fine typography, thin lines, gradient fills, multiple colors, or detailed illustration looks professional at full size. At 16×16 pixels, those same details compress into an unreadable smear of colored pixels. Many website owners convert their full logo to ICO, publish it, and then wonder why their favicon looks like noise.

✅ Fix: Create a simplified favicon-specific version of your brand mark. Use a single bold letter, a simplified geometric version of your logo, or just the most recognizable mark element without text. Test it at actual 16×16 pixel size before committing to the ICO conversion. Bold, simple, high-contrast designs always win at favicon sizes.

❌ Mistake 3: Generating a Single-Size ICO (Only 32×32)

Many generic online image converters that happen to support ICO output only generate a single-size ICO containing one 32×32 image. This looks fine in most browser tabs but is blurry on retina/HiDPI displays, small in Windows shortcut views, and may be wrong for the 16px browser tab rendering. Most users don't realize their ICO is single-size until they notice the blurriness on certain devices.

✅ Fix: Use a favicon-specific tool (favicon.io, icoconvert.com with multiple sizes checked) rather than a generic image converter. Explicitly check how many sizes are in your ICO output — you want at minimum 16px and 32px, ideally 16, 32, 48, and 64.

❌ Mistake 4: Placing favicon.ico in a Subfolder

Putting the favicon at /assets/favicon.ico or /images/favicon.ico and pointing the link tag there will work for browsers that follow the link tag. However, many automated systems — crawlers, browser lookups, some email clients, and some social media platforms — automatically look for /favicon.ico at the root domain. If it's not there, they show nothing.

✅ Fix: Always place favicon.ico in the website root directory (the same folder as your index.html). Even if you also reference other icon sizes in link tags from subdirectories, the .ico file specifically should always be at root.

❌ Mistake 5: Forgetting to Hard Refresh After Updating

Browsers cache favicons very aggressively — sometimes for days. After uploading or updating your favicon.ico, many developers think their favicon isn't working because they still see the old icon (or no icon) in the tab. This is a caching issue, not a deployment issue. The new favicon is served correctly — the browser just hasn't picked it up yet.

✅ Fix: Do a hard refresh — Ctrl+Shift+R on Windows/Linux, Cmd+Shift+R on Mac — after uploading. For even more reliable cache-busting during development, append a query string to your favicon link tag: <link rel="icon" href="/favicon.ico?v=2"> — increment the version number each time you update the file.

❌ Mistake 6: Only Implementing the ICO and Skipping Apple Touch Icon

On iOS, when a user saves your website to their home screen (Add to Home Screen), Safari looks for an apple-touch-icon — a 180×180 PNG file. If it doesn't find one, it screenshots your webpage as the icon, which almost always looks terrible. Many developers add favicon.ico and stop there, not realizing mobile home screen icons are a completely separate requirement.

✅ Fix: Use favicon.io which generates apple-touch-icon.png (180×180) alongside your ICO file automatically. Add <link rel="apple-touch-icon" href="/apple-touch-icon.png"> to your HTML head. This takes 30 seconds of extra effort but covers the full spectrum of icon contexts.

Frequently Asked Questions

These are the most common real questions people have about ICO conversion and favicon creation:

What is the difference between ICO and PNG for a favicon?+
The ICO format can contain multiple image sizes inside a single file — 16×16, 32×32, 48×48, and more — and the browser or OS picks the most appropriate size for each context automatically. A PNG file contains only one size. Modern browsers (Chrome 4+, Firefox, Safari) actually accept a 32×32 or 48×48 PNG as a favicon via the link tag, but older browsers, Windows desktop shortcuts, and several automated lookup systems specifically require the ICO format at the domain root. For maximum compatibility across all browsers, devices, and systems, favicon.ico is still the correct primary implementation — supplemented by PNG files for Apple and Android contexts.
Can I use a JPG as the source for my ICO favicon?+
Technically yes — most converters accept JPG input. But it's not recommended for two reasons. First, JPG doesn't support transparency, so your favicon will have a visible background color (usually white) instead of being transparent. This means the icon looks wrong on dark-mode browser themes and colored tab bars. Second, JPG is designed for complex photographic images — at 16×16 pixels, the JPEG compression artifacts become very visible. For best results, always use a PNG with transparent background or an SVG as your source. If you only have a JPG, remove the background first using a tool like remove.bg, save as PNG, then convert to ICO.
Why is my favicon not showing up after I uploaded it?+
The most common causes: (1) Browser favicon cache — browsers cache favicons aggressively. Do a hard refresh with Ctrl+Shift+R (Windows) or Cmd+Shift+R (Mac) and wait a few seconds. (2) File not in root directory — make sure favicon.ico is in the same folder as your index.html, not in a subfolder. (3) Missing link tag — while browsers look for /favicon.ico automatically, adding the explicit link tag in your HTML head ensures reliability. (4) Hosting delay — if you just deployed, some hosting platforms take a minute to propagate changes. Wait 2–3 minutes and refresh. If it's still not showing, use realfavicongenerator.net/favicon_checker with your domain to diagnose the exact issue.
What size should my favicon source image be?+
The ideal source image for ICO conversion is a square PNG or SVG at 512×512 pixels or larger. 512×512 gives the converter enough resolution to produce clean 16px, 32px, 48px, and 64px versions by downscaling. Smaller sources (like 100×100 pixels) can work but may produce slightly softer results at larger ICO sizes. The image must be square — if your logo is rectangular, add equal padding on the shorter sides to make it square before converting. For transparency, use PNG with alpha channel or SVG. Never upscale a small image to make it larger — start with the highest-resolution version of your logo you have.
Do I need a separate favicon for iOS Safari and Android Chrome?+
Yes. iOS Safari uses apple-touch-icon.png (180×180 pixels PNG) for home screen icons when users tap "Add to Home Screen." Android Chrome and PWAs use icons defined in site.webmanifest — typically 192×192 and 512×512 PNG files. These are completely separate from favicon.ico and are not read from the ICO file. Use favicon.io which generates all of these in one download alongside the ICO file. Add the link tag for apple-touch-icon in your HTML head, and reference the manifest file. Without these, iOS and Android home screen icons will be an automatically generated screenshot of your page, which almost always looks bad.
Is it free to convert an image to ICO online?+
Yes, completely free with no hidden costs or limitations for standard use. favicon.io, icoconvert.com, and RealFaviconGenerator.net are all 100% free with no sign-up required and no watermarks on downloads. cloudconvert.com and convertio.co have free tiers that are more than sufficient for favicon creation (you're converting one file, not batches). There is absolutely no reason to pay for ICO conversion as a one-time or occasional task — all the best favicon tools are free.
Can I make a favicon from a text letter or emoji instead of a logo?+
Yes — and for many websites, this is actually the better approach. favicon.io has a dedicated "Text" tab where you can type a letter or two, choose a font, background color, and generate a clean favicon directly without needing to provide a source image. Single-letter favicons work extremely well at 16×16 pixels because a bold letter in a contrasting color is recognizable even at tiny sizes. For emojis, favicon.io also has an "Emoji" tab — pick any emoji and it generates a clean favicon from it. These text/emoji favicons often look better in browser tabs than a complex logo shrunk to 16 pixels.
