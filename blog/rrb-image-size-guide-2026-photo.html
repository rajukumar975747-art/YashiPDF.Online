RRB Image Size Kya Hai? (Basic Introduction)

RRB image size guide ek complete specification hai jo railway recruitment board ke online forms mein photo aur signature upload karne ke liye mandatory hoti hai. Agar aap RRB NTPC, Group D, ALP ya anya railway exam ka form fill kar rahe hain, toh image size proper hona zaroori hai.

RRB (Railway Recruitment Board) ke forms mein sabse common problem hai image upload error. Photo size zyada hai toh "File size exceeds limit" error, kam hai toh "Invalid format" error, dimension galat hai toh "Resolution not matching" error aata hai.

Simple bhasha mein: RRB image size ek "rule book" hai jo batata hai ki photo aur signature kitna bada, kitna chhota, aur kaise hona chahiye taaki form ek baar me accept ho jaye!

Aajkal bahut students aur CSC vendors image size proper nahi set karte aur form baar-baar reject hota hai. Is guide mein aapko RRB image size ki exact dimension, KB limit, aur format sab kuch samajhaya gaya hai.

RRB Photo Dimension & Size Requirements (Exact Details)

RRB form mein photo upload karne ke liye yeh exact requirements follow karein:

📸 RRB Photo Exact Requirements:
• Dimension: 200x230 pixels (Width x Height)
• File Size: 50KB - 70KB
• Format: JPG/JPEG only
• Resolution: 300dpi (minimum)
• Color: RGB color mode
• Background: White ya light color

Format JPG/JPEG PNG, WebP accept nahi hote
Resolution 300dpi Quality maintain ke liye
Color Mode RGB CMYK nahi use karein
Background White/Light Dark background avoid karein

Photo Quality Guidelines:

  • ✅ Photo clear aur sharp hona chahiye
  • ✅ Chehra fully visible hona chahiye
  • ✅ Eyes open hona chahiye
  • ✅ No glasses (except medical)
  • ✅ No headwear (except religious)
  • ✅ Recent photo (last 6 months ki)

Yaad rakhein: Agar photo dimension 200x230 nahi hai, toh form reject ho sakta hai. "Invalid image" error aata hai.

  • ✅ Original signature hi use karein

Common Mistakes jo Log RRB Image Mein Karte Hai

Log RRB image size set karne mein kuch common mistakes karte hain. Inhe avoid karein:

❌ Mistake 1: WhatsApp Photo Direct Use Karne
WhatsApp se download kiya photo quality kam hota hai. Dimension aur KB proper nahi hota. Original photo use karein.
❌ Mistake 2: Dimension Galat Set Karne
200x230 ki jagah 200x200 ya 230x230 set karte hain. Exact 200x230 hona zaroori hai. manually set karein.
❌ Mistake 3: Compression Se Quality Loss
KB kam karne ke chakkar mein photo itna compress karte hain ki blur ho jata hai. Quality maintain karein.
❌ Mistake 4: PNG/WebP Format Use Karne
JPG ki jagah PNG ya WebP format use karte hain. RRB sirf JPG accept karta hai. Convert karna zaroori hai.
❌ Mistake 5: Resolution Kam Karne
300dpi ki jagah 150dpi ya 200dpi set karte hain. Resolution kam hone se quality loss hota hai. 300dpi maintain karein.
❌ Mistake 6: Signature Cut Hone Dene
Signature 150x50 mein properly center nahi karte, signature cut ho jata hai. Center mein rakhein.
